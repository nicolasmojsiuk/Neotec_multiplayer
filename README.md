# Proyecto Final – Analista de Sistemas  
## Sistema de Gestión NEOTEC

## 📌 Descripción
NEOTEC es un sistema de gestión desarrollado como proyecto final para la carrera de Analista de Sistemas.  
El sistema surge a partir de la necesidad de contar con una herramienta informática que permita mejorar la organización y el control de los procesos internos de una empresa del rubro tecnológico.

El desarrollo del proyecto contempla las etapas de análisis, diseño y construcción de un sistema de información, aplicando los conocimientos adquiridos a lo largo de la carrera.

---

## 🎯 Objetivo del proyecto
Desarrollar un sistema de gestión integral que permita optimizar la administración interna de la empresa, centralizando la información y facilitando la toma de decisiones estratégicas.

---

## ⚙️ Funcionalidades del sistema
Para el desarrollo del sistema se implementa una solución que integra y amplía las funcionalidades propuestas inicialmente, avanzando hacia una gestión completa y estratégica.

El sistema incluye:

- **Gestión de usuarios**
  - Control de acceso a la plataforma.
  - Administración de permisos y roles.

- **Gestión de stock**
  - Administración del inventario de productos.
  - Control de disponibilidad y movimientos.

- **Gestión de ventas**
  - Registro de transacciones de venta.
  - Seguimiento de operaciones comerciales.

- **Gestión de taller**
  - Administración de equipos en reparación.
  - Establecimiento de un orden de prioridad para los trabajos.

- **Sistema de caja**
  - Control de transacciones de efectivo.
  - Registro de ingresos y egresos.

- **Presupuestos de reparaciones**
  - Generación de presupuestos para clientes.
  - Seguimiento de presupuestos emitidos.

- **Gestión de clientes**
  - Captura y almacenamiento de información de clientes.
  - Seguimiento personalizado.

- **Análisis de ventas**
  - Análisis de datos para apoyar la toma de decisiones informadas.

---

## 🚫 Funcionalidades no incluidas
El sistema no contempla las siguientes funcionalidades:
- Facturación.
- Pago de empleados.
- Gestión de proveedores.

Estas quedan fuera del alcance del proyecto actual.

---

## 🛠️ Tecnologías utilizadas
- Lenguaje de programación: **Java**
- Interfaz gráfica: **JavaFX**
- Base de datos: **MySQL**
- Herramientas de desarrollo:
  - Git y GitHub
  - IDE: IntelliJ IDEA

---

## 🧩 Arquitectura del sistema
El desarrollo se lleva a cabo internamente, con un enfoque en los distintos sectores de la empresa, manteniendo una estructura modular que facilita el mantenimiento y la escalabilidad del sistema.

---

## ⏱️ Planificación
El proyecto fue desarrollado considerando un cronograma ajustado a la complejidad del sistema y a los recursos disponibles, con una duración aproximada de **un año**.
